# ⚡ ClashOfCode | Clash of Clans Player Tracker

A lightweight, full-stack portfolio project designed to pull, secure, and display real-time player statistics from the Supercell Developer API using a Python backend and a modern HTML/Tailwind CSS frontend.

## 🚀 Features
- **Automated Data Pipeline:** A Python script utilizing the `requests` library to securely fetch live player metrics and JSON payloads.
- **Dynamic Frontend Dashboard:** Built with HTML5, JavaScript (Fetch API), and Tailwind CSS for a responsive, dark-mode user interface.
- **Targeted Stat Tracking:** Displays core Town Hall metrics, trophy counts, specific competitive troop loadouts, spells, and hero equipment levels.
- **Secure Credential Management:** Implements local configuration separation (`config.py`) paired with strict `.gitignore` patterns to prevent sensitive API keys from being exposed on version control.

## 🛠️ Tech Stack
- **Backend:** Python (`requests`)
- **Frontend:** HTML5, JavaScript, Tailwind CSS
- **Data Storage:** JSON
- **Version Control:** Git & GitHub
